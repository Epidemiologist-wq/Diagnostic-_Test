# Diagnostic Test Analysis in R

## About the Project
This project uses R to evaluate the performance of a diagnostic test. It focuses on statistical measures used to assess how accurately a diagnostic test identifies individuals with and without a condition.

## Objectives
- Evaluate diagnostic test performance.
- Calculate sensitivity and specificity.
- Estimate positive predictive value (PPV) and negative predictive value (NPV), where applicable.
- Calculate overall diagnostic accuracy.
- Interpret results to understand the usefulness of a diagnostic test.

## Tools and Technologies
- R programming language
- RStudio (optional)

## Project Files
- `MATH_515-Diagnostic-_Test.R` — R script for diagnostic test analysis.

## How to Run
1. Install R on your computer.
2. Open the R script in RStudio or another R environment.
3. Check that any required packages and input data are available.
4. Run the script to perform the analysis and view the results.

## Key Diagnostic Measures
- **Sensitivity:** The proportion of people with the condition correctly identified by the test.
- **Specificity:** The proportion of people without the condition correctly identified by the test.
- **Positive Predictive Value (PPV):** The probability that a person has the condition given a positive test result.
- **Negative Predictive Value (NPV):** The probability that a person does not have the condition given a negative test result.
- **Accuracy:** The proportion of all test results that are correct.

## Applications
Diagnostic test evaluation can support epidemiological research, clinical research, and public health studies.
